# 独立记忆部署与知语远程接入

## 本轮决策

被控对象是知语桌面记忆操作的执行位置和可恢复性。独立服务使用独立 PostgreSQL 数据库保存身份、权限纪元和传输审计；安装知语项目 Adapter 执行现有观测、候选/审核/修订、依赖、文件、查询与 ContextPack 合同。知语旧业务表仍是唯一主记录，暂不复制到通用示例 schema。服务进程与 Web 进程分开，核心不导入知语；项目安装模块由可信部署配置指定，不能由 HTTP 注册。

这属于兼容部署，并非完成旧业务表的物理数据库搬迁。后者需要单独的数据转换、写入冻结和逐版本校验，本轮不借上线远程入口改写历史审核或来源。

## 接口与权限

桌面经现有登录验证后，服务端选择绑定该 owner/zhiyu namespace 的私有身份令牌，调用已安装的 project.call 操作。请求不能提供 owner、namespace、任意方法名或接收地址。项目操作限定 owner.submit/read/explain、status 和 dispatch.authorize；每次在服务身份事务内重新认证/授权，持有身份共享锁直至操作结束，拒绝优先。业务方法继续执行现有严格解析、版本/CAS、来源与权限核验并写原业务审计。传输审计仅记录操作、时间、身份和结果，不记录正文或令牌。

Work 执行不能借 owner 入口升级权限。模型出站的不可序列化 proof 与 ALS 仍由实际运行进程的项目适配层保管；原来的最终来源/版本/授权重验和 SDK hook 保留。远程模式下 owner chat 的出站增加服务端 use 授权检查；这不是将 JSON Pack 作为证明，也不将传输授权当作来源证明。Work lease 仍在其原运行进程核验，不跨进程序列化。

## 回退和反馈

模式为 remote 或 local，由服务端配置显式切换。远程错误不自动重放写命令、不自动切本地、不伪装空结果。超时写入结果可能未知，用原 commandId/receipt 对账。回退只切执行位置，同一主记录无同步延迟。回退不绕过来源撤权、审核和模型出站检查。页面展示当前模式、服务连通状态、失败原因和回退说明；秘密不进入浏览器。

服务由独立监督进程运行，包含重启退避、心跳、最近启动/退出原因、日志脱敏与停止文件。Web 生产切换保留原版本；停止的业务 worker 保持停止。部署配置与凭证保存在被 Git 忽略且限制 ACL 的目录，仓库仅提交启动工具和说明。

## 验收

先在隔离库测试服务认证、跨 owner 拒绝、原命令幂等、审核修订、来源/期限变化、召回字节预算、远程失败不重放与本地回退，再回归原真实 PG/SDK 出站保护和独立服务测试。最后用日常桌面入口验证真实历史记忆、固定版本和回执；不批准用户日常候选，不唤醒 Work/Loop。生产构建和回退版本总数不超过两套。
