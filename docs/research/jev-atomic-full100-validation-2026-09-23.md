## 修复行为与边界

1. `platformRecall` 对历史或未解析时点的统计请求返回 `unsupported_time`，不调用只支持当前状态的统计读取器。空 results 明确表示未读取，不代表零条。观测时间在读取结束后计算，避免把本轮观测误判为未来。
2. 历史问题进入模型前附带证据边界，禁止把当前查询时间当成历史快照时间；这一边界也适用于内容工具和路由回退。
3. 首轮、无上下文和附件、只说“截至评测快照”等却没有可定位日期/编号的统计请求，直接请求快照信息。保留既有会话、附件和明确快照标识的正常检索路径。该规则有意限定范围，并不保证所有自由表达或后续会话都不会过度读取。
4. 路由事件显示为“资料来源判断”，给出来源或回退说明；原始 JSON 留在“诊断详情”。界面转换不修改存储事件，不把来源选择写成事实已验证。
