# 正文搜索连续分页验收

## 实现

正文搜索新增 nextCursor/cursor，按保存时间、ID 降序使用 keyset 条件读取下一页。游标绑定用户、Work、原查询、类型与显式时间过滤；续页保留第一页 searchCutoff，不能扩大原时间限制。每页仍执行原权限条件；游标是未签名的续查元数据，不是授权凭证，查询指纹用于防止误用，不承担认证职责。

内部排序位置从数据库时间文本保留微秒，不经 JavaScript Date 截断。分页位置不参与快照正文哈希，保证搜索→精确展开的 expectedHash 一致。askMemory 支持传递游标，并纳入重复查询键。列表、目录和精确快照仍保留原接口；非法游标不会静默退回第一页。

第一页默认冻结为当前保存时间上界，新的正常插入不进入后续页。但这不是跨请求数据库事务，修改、删除和回填旧时间仍可能影响结果；末页也不证明语义覆盖。结果会明确披露这些限制。

## 测试

七文件 104 项测试通过，覆盖微秒位置不丢失、多页无重复、固定上界、查询/主体变更拒绝、时间范围不扩张、非法游标、SQL 条件以及统一入口续页，另回归快照哈希展开和现有权限接线。
