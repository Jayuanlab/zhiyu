# 历史快照正文检索验收

## 实现

brainListSnapshots(view:search, contentQuery) 对授权范围内 snapshot.content 的 JSON 文本执行不区分大小写的字面匹配，用户/Work/时间/类型条件均在数据库中合取。查询词参数化，`!`、`%`、`_` 按字面转义；不会扩大为任意 LIKE 通配匹配。搜索查询长度 2–200 字符，最多十条候选并多取一条标记 hasMoreMatches。

每个候选返回最多 1,200 字符的邻近片段、ID、类型、作用域、保存时间及 snapshotHash；后者是精确快照读取同一序列化记录的哈希，可直接作为 expectedHash 校验后续展开。askMemory.reads 新增 snapshot_search 委托同一工具，不增加读取身份或权限。正文搜索不进入目录复用缓存。

该搜索不是语义检索，可能匹配 JSON 字段名而非事实值；数据库文本表示与序列化片段存在差异时 matchLocatedInExcerpt 可为 false，不能伪称片段定位成功。零命中只说明本次词组/范围未匹配，失败不伪装空列表。没有历史回填、记忆晋升或自动任务。
