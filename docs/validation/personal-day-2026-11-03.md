# 个人日计划本地实施验收（2026-11-03）

## 实现与边界

- 入口：桌面侧栏「个人日计划」，`/?page=personal-day`；包含日计划、身体档案、训练、饮食、资料与依据、进展与记录。
- 一份结构化档案与事实源；测量、更正、执行、计划候选与采用事件分层保存。训练记录实际用时、动作、组数、次数、负重、主观用力；餐食记录实际克数、生熟/包装状态及营养标签关联。
- 今日/明日规划；固定事项名称在模型输入中隐去。Pi 共享配置中心的默认智能体连接，只能选宿主目录、缩小已知窗口、提出地点和就餐变化。不能改写身体状态、历史事实、固定事项、权限或扩大时间窗口。
- 草稿核对后采用，临时变化先标明待处理；保留完成/部分完成/进行中/已过时间未确认事实。未完成事项加入明日待评估池，不伪造已安排时间，不把漏餐变成次日补吃任务。
- 全局版本和采用时的实时约束校验；命令先占位、同输入重放、不同输入拒绝。迟到模型结果不能覆盖新状态或已解除的中断操作。暂停、沿用仍可行原计划、恢复仍可行旧安排、原始记录导出和更正均有入口。
- MD/TXT/PDF/DOCX/EPUB 导入复用本机转换器；原件和正文加密，解析失败显式显示。Pi 提取最多前 12000 字符的原则候选需要独立勾选同意，仍须人工核对采用。扫描 PDF 不伪装 OCR 成功。
- 五张 `personal_daily_*` 表以会话 owner 过滤，正文使用本机加密密钥保护。HTTP 拦截跨站、伪造 owner、会话切换后旧表单，响应 private/no-store。日志不输出模块正文和密钥。
- 持续任务接入原有 Work/Loop/Worker，不新增独立 cron。持久化车间角色决定领域控制器，不能依赖可能重置的临时连续性状态。租约与关联 Loop 检查、denied 优先、只读角色拒绝、原生审批检查均在保存草稿前生效。默认关闭，永不自动采用或发送消息。
- 持续任务显示后台在线/心跳、最近运行、下次运行、失败与暂停状态。本地程序关闭时不能执行。

## 适用条件与遗留项

- 当前范围为一般成年人日常计划，有限动作和食谱目录，标签营养换算；不提供医学处方、康复诊断或精确能量治疗方案。只有用户核对来源与实际执行，才能逐步评价长期效果。
- 更丰富的动作/食谱、自动周期复盘、食品数据库、设备同步、OCR、语音输入、外部日历/消息/购买与时区切换保留后续实施。未做移动端或原生客户端专项验收。
- 删除覆盖模块在线五表及临时转换正文；会先通过 Work 命令暂停关联 Loop。通用 Work 只保留任务运行元数据和不含身体字段的保存回执；部署备份保留，外发模型数据无法通过本地删除撤回。
- 原有量化模拟盘 Worker 的 `paper_migration_required` 与本模块无关，保留显式状态，不标记为已经修复。
