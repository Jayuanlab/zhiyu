- 响应与决策绑定到同一次生成结果；跨模型及同模型不同结果均拒绝。可选事项暂不跟进仍需要代码验证的原有事实、来源及风险条件，必审和恢复权保留。
- 修复明确请求 active、candidate、rejected 时的状态解析组件；完整证明缺席组可计零，部分读取或失败不能推断零。review80 实测发现当前 agent 入口没有加载旧最终渲染 session，因此不能把组件测试当默认功能已恢复；最后的 review81 修正放在真实工具返回的明确逐项数据上，不启用全局强制模板。
- `observeWorkshop(view="runs")` 提供 owner 车间最近运行发现，默认最近一条，再按真实 run ID 使用原结果 reader。`complete` 仅表示该摘要字段读完，不代表全部报告或业务质量通过。
- Typesafe/Jev 的调用接口、HTTP 代理、超时与脱敏代码保留。显式诊断入口仍可调用，默认业务路径退出自动调用。
