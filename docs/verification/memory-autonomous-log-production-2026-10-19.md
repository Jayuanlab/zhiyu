## 原因与修复

[上一阶段](./memory-read-boundary-production-2026-10-19.md)三轮业务通过，但模型 LOG 为零，宿主提交三次。两轮没有尝试，另一轮六次拒绝涉及本轮版本与历史版本混同、未知来源以及无证据事实。原失败和原产物保留，没有重新计为成功。

本次修正事实字段 schema，明确事实必须带当前可引用证据；expectedVersion 指向本轮 read 的版本。普通自由研究在 apply 模式、有当前合格读回执且工作记忆工具仍获准时，向实际提供方上下文加入有界的本轮版本、接受 LOG 次数、回执 ID 和通用保存协议。只传可信状态，不将来源散文提升为指令。缺少工具、被拒、试运行或没有合格读取时不建议保存；已有 LOG 后停止建议，无进度变化不要求保存。

模型仍自行决定并真实调用 read/update；没有强制工具选择或追加模型轮次，没有把 LOG 加入业务验收。宿主兜底、版本冲突、来源校验、denied 优先、预算和审计失败处理均保留。原目标、Skill、模型、权限、业务检查与每轮 40 工具、48 物理请求、900 秒上限不变。每个普通命令只运行一次，不重试失败来补成绩。
