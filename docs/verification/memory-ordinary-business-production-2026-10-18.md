# 普通业务记忆修复与连续生产观察

普通业务记忆修复已部署并完成真实观察，但尚未达到完整通过，具体边界见下表。 这不代表长期记忆自动获批、旧断言被重新认可，或所有场景已稳定。

## 实际改动

普通 Pi Work 的工作记忆不再依赖专门的论文验收合同。研究任务可保存带版本与来源目录的 LOG，不压缩正文时可省略压缩参数；来源编号、权限、版本和时效检查保留。

业务检查点完整存入审计事件，下一轮按原回执、范围、校验值和有效期恢复有界问题与复查条件。报告 JSON 内嵌代码块不再截断解析，结构字段不能由散文伪补。车间硬拒绝规则传到 Loop，拒绝优先于允许；最终动作检查读取真实运行快照。

网页优先直接读取并保留原文身份，合法公开跳转逐跳检查；代理回退继续标记目的地址未经独立核验。续读可提交同 Work 的证据编号和偏移，恢复同一份保存正文；域名与日期过滤进入实际搜索。

普通交付保留一次有限修正、最多四次转发，最后一次不再提供工具，为最终报告留位置。普通自由研究报告使用独立五分钟请求上限，原短交付仍为两分钟，Loop 整轮仍为十五分钟。超时和不完整流不自动重试，不能重复业务动作换取成功。

完整边界见[框架说明](../architecture/ordinary-business-memory.md)。

## 最终版本三轮结果

同一既有研究车间与 Loop，原目标、Skill、模型、权限、来源与校验规则不变；没有专门验收提示，没有植入纠错。运行时提供通用记忆使用说明和原业务校验反馈。本阶段为环境代理配置后的同一编译版本 review86，构建与构建后类型检查通过，517 项单测及 15 项观察器检查通过。

## 保存、召回与纠错的准确口径

- LOG：本阶段接受 0 次，是否进入后续真实请求见[脱敏记录](./evidence/memory-ordinary-business-production-2026-10-18.json)。普通日志或最后报告不算 LOG 保存；不要求每轮为了验收而写一条。
- 检查点：只继承已支持的结构化进度字段，完整原文继续留在审计记录；不把模型断言和行动建议自动变成长期事实。
- 召回：每轮核对当前数据库版本与真实模型输入，摘要条目不冒充全文。工作笔记跨轮仍保留“未经核验”的身份。
- 纠错：若当前 Brain 存在纠错信号，宿主抑制旧事实、假设和行动建议，只接续未决问题。按此路径通过不代表整份旧事实已原样复用。本次新增主人事实纠错的版本化生产样本：未证明。
- 长期候选：本阶段新增 2 条，自动批准 0 条。候选与已经生效的长期记忆分开统计。
- 网页：本阶段实际续读 6 次，同一保存正文身份校验结果逐条保留；一次成功读取不能证明网页内容或研究结论正确。

## 失败没有删除

最初 review84 两轮共 48 次请求：一轮通过，另一轮暴露可选参数与宿主解析不一致、最终报告转发预算不足，LOG 两次均未保存。该轮只读收集器漏识别同执行租约的 Brain 候选回执，原始 HTTP 202 响应没有落盘，缺失明确保留；后续收集器先保存准入响应。没有重跑同命令或改写失败成绩。

随后 review85 三轮共 66 次请求：前两轮完成并通过，第二轮首次自然保存 LOG，第三轮接续了问题状态，却在 120 秒上限处因不完整模型流失败，清理完成。仅 HTTP 200 和输入用量帧不算完整响应。五分钟策略修复这个已知边界，不证明提供方内部停顿原因或重放该请求一定成功。原阶段独立审计器对 agent_trace、候选写入及失败 Work 短回执的识别错误保留原结果，并以同范围、同 worker 和同 fencing token 的只读规则另行核对。业务失败没有被审计修订改成通过。

对该次自然 LOG 的补充只读核对证明：保存回执与版本匹配，下一轮实际输入包含对应检查点；当前 Brain 纠错信号触发后，仅继承一个未决问题，旧事实、假设、行动建议和来源引用均未携带。完整旧事实继承仍未证明，原失败成绩保持不变。

review86 的五分钟上限阶段继续运行两轮，共 16 次请求，均因连接中断失败；其中一次在上限前发生断开，不能说延长超时已解决连接问题。120 秒失败流实际收到 1944 个解析帧，缺少结束帧；不是完全没有输出。

随后保留同一编译版本，启用机器已有的环境代理配置并明确本机绕过、保持 TLS 校验，执行本表三轮。独立的四次无凭证公开页面 HEAD 检查不计入模型请求；没有新增认证试探。配置与代理 dispatcher 可观测，但没有逐推理请求的套接字路由证明，也不能把效果变化归因于代理。

本次请求的前置诊断共 7 个业务命令、130 次生产模型请求；加本阶段共 10 个命令、232 次请求。全历史累计 22 个命令、388 次生产请求，早期认证诊断 5 次另计。实际费用未测量。

## 仍有边界

输出长度上限、缺失结束帧、连接中断与校验未通过分别记录。工作记忆可用并不保证模型会在失败前主动保存 LOG；这次观察不能替代正常任务稳定完成的证据。三轮是小样本，不能证明长期稳定。纠错保护下未恢复的旧断言、尚待审核的候选、未新增验证的主人语义纠错，均不标记已完成。桌面页面能够区分来源目录、保存次数和历史跳过原因；通用持仓措辞与研究目标摘要不完整仍是既有 P2 展示项。私人身份、原始输入输出和内部存储位置不发布。

收尾已移除临时观察器并回读正式服务：Web 与所选车间的执行 worker 在线，没有在途任务，原业务配置和任务状态保留。生产构建与绑定源码一致。
