# 通用记忆 G4：独立项目完整接入验收

日期：2026-10-21。分支：`codex/general-memory`。目标：用真实独立项目接入 R/K/U，验证候选、审核修订、召回、ContextPack 和出站；不改写知语历史数据，不启用共享旧表或远程使用凭证。

## 实施与接入

- 新增 `packages/memory/src/knowledge.ts` 与 `knowledge-contracts.ts`，将 G3 治理、依赖判定、候选选择、预算和使用作用域组合成可绑定认证会话的知识 facet。命令严格拒绝未声明字段，禁止正文自报审核、来源核验或 namespace。观测 facet 继续 G1 合同，不改变知语旧 DTO。
- 新增独立 PG 知识 Adapter。当前记录、历史版本、命令回执和审计分别持久化；所有主键/查询/锁/幂等均含 tenant/project，命令回执另含 principal。历史、命令与审计表只追加。状态变化和回执在同一事务提交，失败不宣称保存或准入成功。
- 独立研发项目 `examples/memory-project/knowledge-project.ts` 自己安装认证会话、成员权限、文档 reader 与模型消费者，并组合 G1 观测 client。自己的文档、成员、来源授权与通用表运行在空数据库；未运行知语迁移，无 Next、Work、Loop、Brain 或应用 schema 依赖。
- 业务策略沿用独立研发规则：构建日志为 2 小时运行记录，不能整篇提升长期理解；团队规则候选默认 90 天、最大 180 天复查，未知内容拒绝长期准入。知语的 24h/7d/30d/90d 规则没有改动。
- 来源版本覆盖真实正文、来源版本、时间与期限；摘录按 Unicode code points 精确核验。正文在摘录外改变也能使旧 Pack 失效。来源 permission 和成员 denied 优先于 allowed；治理读取、历史回执及重放也重验来源权限，防止通过旧结果读回撤权摘录。
- 修订保留历史与前序，旧版退役、新版待审，期限不因改写或重试延长。过期后需新证据、显式提案和重新审核。策略痕迹记录实际输入与版本，不作为业务事实背书。
- ContextPack 区分理解、完整限制与固定来源证据，预算单位为 UTF-8 字节上界。没有权威 CI 当前状态时 `currentStates` 为空，不把旧构建日志当当前状态。复制 JSON、未登记消费者、跨项目 Pack 不能出站。
- 每次登记消费者交付前，以短事务重验记录、来源、权限、期限与审计提交；模型发送在事务之后。使用回执区分 admitted、dispatched 和 outcome_unknown；异常不自动重发。只承诺已登记进程内单次逻辑请求，不承诺其他调用路径无法绕过，也不证明模型采纳或业务动作执行。

## 独立验收与反馈

`examples/memory-project/acceptance.ts` 可以单独以 Node + PostgreSQL 运行。只初始化通用/示例表，用自身 loopback HTTP 接收器验证真实交付次数，未调用真实提供商。临时库名称校验只是测试删除保护，不是生产接入限制；外层测试管理者负责建库和删除。

14 组覆盖：R/K/U 同会话组合、并发命令与语义去重、伪造身份与提权字段、未注册来源与伪造摘录、候选隔离/审核与 90 天期限、Unicode 精确证据与实际 Pack 交付、同人同 commandId 跨项目、修订及再次审核、来源变化、成员/来源撤权、到期不续期与新证据恢复、消费者失败未知结果及回执查询、延迟提交失败零出站、候选与历史/回执原子回滚、跨租户/来源到期/180 天硬上限/主动退役/历史不可覆盖、策略输入标签与重复提案改期限拒绝。完整用例名称以机器证据为准，组内包含多个断言。

另补三项契约检查：明确来源拒绝形成有界 omission；提供商 503 和带 code 的数据库异常必须中止，不能伪装成空召回。接口检查发现旧命令/治理结果可能携带撤权摘录后，已补当前来源权限重验并加入真实 PG 负向断言。语义指纹补入标题与业务标签，重复提案不能偷偷改期限；畸形成员权限配置拒绝使用。出站成功与未知均可通过绑定身份的回执入口核对，不能用别的项目身份查到。

## 使用边界与恢复

示例是经过隔离验收的独立接入实现，不是已部署的多租户产品。认证发行、来源真实性和消费者实现属于可信宿主；不能通过用户请求安装 Adapter。示例 `send` 合同是一条逻辑请求，多轮/重试须逐次进入保护入口。现有知语多轮 Pi/非 Pi 仍沿用 G3 已接入的运行时 hook。

来源当前版本不匹配时拒绝固定证据读取；没有文档旧版本库时，不用当前正文冒充旧版。历史回执的原结果不证明当前有效，读取它也需当前权限。到期停止使用而不删除原文；停用和新提案留历史。独立库回退与知语实例无关，知语代码回退保留前一生产产物，不回滚日常数据库或删除审计。

操作入口与调用合同见 [独立项目说明](../../examples/memory-project/README.md)。确定性去重按已声明输入字段计算指纹，不声称自动识别所有自然语言同义改写，也不替代独立审核。
