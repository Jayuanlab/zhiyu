# 记忆中心产品与桌面展示验收

日期：2026-10-21（北京时间）。状态：开发验证、正式构建、日常 3515 切换及实际桌面复核完成。

## 定位与落地

需要保留全局记忆入口，承担跨来源查找、审核纠错与依据追溯。页面名称改为“记忆中心”；原“个人记忆”入口按实际内容改为“消息与知识”，负责微信来源、知识整理、待办和沟通理解，两个入口互相可达。没有另建记忆存储、复制业务真相或扩大智能体权限。

默认页从技术说明和维护控件堆叠改为问题输入、来源选择、最近更新的真实记忆及查找结果。检索设置折叠，摘要与待办、知识资料、沟通记录、关系图谱统一使用中文。最近记忆只取 8 条，展示状态、时间、正文预览及已有纠错入口，不编造总量、健康度或“已核实”结论。

四个分区：查找记忆、审核与纠错、文件与接续、来源与使用记录。首次访问才装载后面三个分区，访问后保持表单和未确认命令；旧 `#memory-private-files` 链接继续有效。未确认修订和提案恢复提示全局可见，审核保存后同时刷新最近记忆和已有查找结果。读取或模型出站准入仍不等于模型已采用或领域动作成功。

设计依据见 [产品定位与信息架构](../plans/memory-center-product-design-2026-10-21.md)。

- 新最近记忆测试验证有界请求、状态语义、失败不伪装为空、响应超界不展示正文。
- 全量 TypeScript 零诊断；源码在测试前后稳定。最终匹配正式源码的测试记录和摘要登记到本报告机器证据中；独立类型检查为 `.runtime/memory-technical-plan/memory-center-types.json`。
- 开发模式实际桌面 3618：真实日常身份、读取 8 条最近记忆、审核列表读取、文件入口、来源回执、公开验收标记检索成功；切换分区保留输入，没有 mock 页面 API，没有执行审核或清理操作。控制台检查未观察到 error。开发服务器已停止，共享 Next 配置已恢复，无冲突。

实际日常桌面已读取 8 条最近记忆及 5 条当前更新提案样本，核对四个分区、原文件锚点、查找提交、输入保留和键盘从问题输入到查找按钮；未提交审核、暂停政策或清理文件。921×708 / 1280×720 的页面宽度分别等于视口，主搜索按钮底部为 587 / 523px，均在首屏，标题位于内容区内。最终页面复测未观察到 console error。停止开发服务后的旧开发标签失效，使用新日常标签重新连接，不把开发停服当作正式服务失败。
