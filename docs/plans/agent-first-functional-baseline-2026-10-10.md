# 先恢复智能体功能，再考虑 Jev 优化

日期：2026-10-10。主人要求推翻之前对 Jev 的使用顺序：先让智能体完成需要的功能和效果，再用 Jev 优化；保留调用方式，恢复项目功能。此方案替代此前默认规则匹配、前置预取与 Jev 助审的产品方向，不是把整个工作树恢复到旧提交。

## 本次范围

恢复桌面 Web 对话、Brain 的生成式规划及车间“AI 帮我决策”主模型路径。对话里的平台操作继续使用实际工具和既有车间命令。保留已经验证的上下文时间精度、接口目录、所有者绑定、来源证明、结果分页和真实执行回执。

同时修复上轮两个直接功能缺口：明确列举记忆原始状态时落实完整统计证明；从车间发现最近运行身份，再读取结果。暂停检索重排、Jev 阈值调优、报告自评分及全平台新增控制层，不扩展手机端、外部发送或调度状态变更。

## 执行路径

```text
当前用户目标与持久上下文
  -> 智能体理解并选择实际接口
  -> 原有所有者、角色和工具权限校验
  -> 读取或执行授权动作
  -> 主模型组织可读结果
  -> 保存真实回执、失败和用户反馈
```

普通对话不再先运行自动资料预取或能力建议；工具仍开放，由智能体决定如何使用。Brain 恢复已有生成式 planner 的配置解析，规则仅用于主配置不可用或生成失败后的明确降级。Brain 有独立模型配置，不承诺与本轮聊天选中的模型完全相同。

车间助审由主生成模型直接给出逐项建议、理由、优先级和待核实内容，不把生成模型输出转换成 Jev 概率再套分数。历史 Jev 记录保留，但不复用作新助审缓存或当前决策依据。模型生成不装载执行工具。

“AI 帮我决策”的既有权限、指纹、事务与恢复机制保留。高风险及必审事项继续交主人审核；可选事项的暂不跟进必须同时满足代码验证的原有事实和风险边界，不由模型自称“风险低”授予动作。报告只有模型判断、没有独立佐证时不能自动关闭。

## 控制模型

| 项目 | 实现与约束 |
| --- | --- |
| 被控对象 | 对话工具使用、记忆规划和本次车间待办建议；长期车间及 Loop 仍由既有 Host 管理 |
| 观测输入 | 当前用户指令、实际工具 schema、完整范围的统计证明、当前所有者车间和运行数据、待办原始事件及局部样本 |
| 新鲜度 | 真实读取时间、来源与范围随回执保留；读取失败或未读不能推出零、没有运行或执行成功 |
| 状态 | 复用聊天、车间事件、运行、待办指纹和决策记录；不新增事实数据库、不改历史观测 |
| 控制动作 | 模型选择实际工具；动作走原 owner 命令、幂等及审核；发现 run ID 只读且不重绑聊天焦点 |
| 安全边界 | denied 优先；关闭 Jev 不解除跨所有者、角色、外发、付款、删除及配置审核限制 |
| 反馈 | 保存原始工具结果、来源缺口、模型结果、失败原因；以任务是否完成和结果是否可用判断改进 |
| 异常与降级 | 主模型无配置、失败或无效结构时明确降为基础整理或规则兜底；不以 Jev 失败阻塞原功能 |
| 用户接管 | 对话可纠错，车间页面提供审核、恢复、暂停及运行查看；不增加重复确认或聊天工作卡 |
| 页面解释 | 普通文本呈现结果；待办建议说明依据，程序完成与业务核验分别表示 |

## 保留 Jev 调用，默认退出业务前置链

`PLATFORM_REASONING_MODE` 默认 `agent`，非法值也回到 `agent`。该基线优先于历史实验 flags，避免机器残留配置重新打开旧流程：

| 环节 | agent 基线 |
| --- | --- |
| Brain planner | llm，明确失败时 fallback_rules |
| 自动资料预取 | off |
| 自动接口建议 | off；实际分页目录仍可读取 |
| Jev 证据检查 | off |
| Jev 定向补读及旧 replace | 不自动执行 |
| 车间 AI 助审 | 主生成模型直接建议；不消费 Jev 缓存 |

保留 `jev-fetch` 的 Typesafe systemone 调用、HTTP 代理、脱敏、超时、响应限制，以及显式调用的 router/evidence/review 函数。直接诊断调用仍须明确参数与授权；保留代码不代表业务自动调用。`optimized` 仅是将来显式实验接入的配置，不是默认值，也不代表已验证优化有效。

Jev 再接入的条件：先有可复现的功能成功基线，再定位某个步骤的等待或费用问题，限定候选和输入，以同任务、同来源、同权限和预算比较。先旁路观察；只在不损失完成效果和边界的情况下替换具体步骤。不得重新让 Jev 判定代替原接口存在、权限或执行回执。
