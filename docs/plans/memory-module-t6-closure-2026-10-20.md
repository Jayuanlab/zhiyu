# T6 Memory 入口与来源收口

状态：T6 核心闭环已实现并通过验收，详见 [T6 验收](../verification/memory-module-t6-2026-10-20.md)。承接 [技术方案](memory-module-technical-plan-2026-10-20.md) 与 [T5 验收](../verification/memory-module-t5-2026-10-20.md)。181 套回归、2177 项测试、完整类型、隔离 PG / 私有对象、开发与全新正式生产产物 HTTP / 桌面均通过；日常数据库与实例未切换。未注册来源明确拒绝或表达时点，不冒充全域支持。

## 控制对象与可验证目标

被控对象是“哪些已存来源能够进入模型输入，以及它们的版本、权限和实际使用记录”，同时退出旧 Brain 的业务实现。原始事件、理解、领域当前状态、读取与控制动作继续分层；Memory 组织身份、来源、准入、证据和治理，领域模块保留自己的写入权威。

基线是 T5 已保存的源码与验收回执。已知缺口为：旧 Brain 剩余修订 / 治理实现、外层直写记忆表、旧 `/api/brain` 实际 handler、未登记的平台记录 / RAG / 历史会话与本地路径，以及零散自动 prompt 装配入口。

本轮接受标准：生产调用不再 import Brain 实现；旧路径仅显式兼容导出；新 HTTP/UI 使用 Memory 入口；列出的已存来源经过实际权威 reader 和逐次出站复核；没有绑定的来源显式拒绝或返回缺口，不能继续裸正文进入同一模型链。覆盖目录同时列出支持与拒绝项，不能把源码迁移数量包装成全部世界数据均可验证。

## 三条实施链

| 链 | 状态与动作 | 反馈与故障处理 |
|---|---|---|
| 实现退出 | 修订草稿、自动更新策略、文档更新、canonical 治理进入各自 Memory 能力；SQL 进入 PG adapter | 保留错误类身份、原幂等 / CAS / 审计；宿主终态事务通过同事务端口写入，失败不留半个结果 |
| 来源准入 | 固定目录的 source kind / 主键 / 真实投影 / 权限 / 完整版本，经可信调用方登记 | 初次读取与每次 Pi 请求前复核；修订、删除、撤权、场景变化和审计故障阻断后续请求 |
| 主人治理 | Memory canonical HTTP 入口、来源覆盖与最近使用记录、已有审核 / 暂停 / 纠错 / 恢复界面 | GET 只读，不自动 backfill / 导入 / 修复；无样本为未观测；主人显式命令保留原审核与版本条件 |

RAG 的索引命中必须回到真实 document / chunk 权威行，不能拿向量摘要当原文。Chat 历史、Work / Loop 历史输入和平台事件必须有可信记录身份及当前可见权限。本地目录与旧公开 URL 不能提供授权，没有已登记绑定时不给模型正文；恢复入口是主人明确导入受管文件。当前业务主记录只代表读取时观测，不能声称是不可变原始事实或外部世界当前真相。

## 边界、扰动与恢复

caller 不能自报主人、Work、表名、任意 SQL、reader 回调或授权。Work 仍受真实租约、保存的角色 / 场景和领域权限控制；拒绝优先，Memory 不新增资金、发送、删除或自动执行业务的权限。内部 source registry 必须是固定、可审计的目录，不能万能包装任意工具返回为已验证来源。

本轮不自动启动 / 恢复已暂停任务，不抓取历史公开云地址，不改写原始事实和历史回执，不用真实模型、资金、消息或业务动作验收。外部工具的一次观测与其后实时状态分别表达；已发出的请求无法撤回，出站保护只约束后续逻辑请求。缺少可信远端重验证机制时明确降级，不伪造完整覆盖。

错误对主人显示安全的 code / detail / warning，不能输出 SQL、原始私有正文或连接参数。必要回执失败不返回成功内容；持久 pending / 恢复状态沿原 commandId 继续。共享配置使用既有隔离验收锁及比较后恢复，不覆盖其他并发修改。

## 匹配评估与交付

先在相同 synthetic 数据上复现未登记、旧版本、撤权和错误来源问题，再检验新入口。测试涵盖正常精确读取、跨主人 / Work 拒绝、同版本伪造正文、查询边界、修订与删除、第一次模型请求成功 / 第二次失效阻断、审核 / 暂停 / 纠错及回执失败恢复。

每个能力保留 unit / API 与隔离 PG 证据；中央开发与全新正式生产产物使用同一冻结源码完成 HTTP 和桌面 1440 / 1024、键盘、可读性及失败恢复验证。最终分别报告编辑保存、程序验证、隔离装载和日常生产切换状态，不把测试通过等同真实业务改进。

源码回退按本轮可审阅文件差异执行；持久数据按已存在的版本化领域命令恢复，不回滚原始事件、审核回执或权限撤销，不重放外部副作用。自动回滚和日常切换未实际运行时必须明确说明。
