## 1. 控制目标
用户能快速看懂当前状态、待处理事项和下一次动作；车间页面职责分离且链接可恢复，不以单纯缩短文件证明重构成功。

## 2. 被控对象
约 11026 行 workshop-client、快照请求、URL 选择状态、审核/报告/配置/记忆面板及无障碍标签。

## 3. 观测输入
页面内混有状态分类和数据聚合；切换状态未同步 URL；状态文案“草60”“已暂”；已有请求合并和旧响应防覆盖值得保留。加载空态不等于业务无报告。

## 4. 状态模型
URL 承担 workId/tab/runId/reviewId；受控表单和临时展开仍为局部状态。快照状态统一为 loading/ready/refreshing/degraded/error，并保留 lastSuccess、版本与 cursor。未知 URL 值有确定回退，无权限目标不泄漏名称。

## 5. 控制器/角色
后端投影 Module 负责业务解释；前端数据 Module 负责请求合并、版本和重验证；显示 Module 负责呈现及命令提交。以这些 Interface 为 Seam 拆分，而非把同一大组件机械切文件。

## 6. 控制动作与工具矩阵
拆分顺序：状态文案 → URL 选择 → 查询 hook → 运行历史 → 审核 → 配置 → 资料/记忆。复用现有 SWR 与请求保护，不新增第二套全局状态库。
用户操作提交 commandId/expectedVersion，进行中禁重复按钮；服务返回冲突后刷新并提示，不能乐观宣称发送成功。首页有限展示待审核、异常、最近完成、下次运行，复用 02/09 投影。

## 7. 边界与审核
URL 仅定位资源，不赋予权限。配置修改展示内容差异并走既有审核；深链接携带资源 ID/版本，不放秘密或正文。原有 pending/unknown/denied 提示在重构中不可丢失。

## 8. 反馈与评价
记录固定设备生产版首次可操作、暖缓存接口 p50/p95、点击反馈、请求数和打包体积。先形成基线，再验收没有明显回退：建议同环境同数据至少 30 次请求，对异常波动复测；不宣称拆文件自然提速。

## 9. 异常、扰动和降级
快速切 A→B 后 A 慢响应不得覆盖 B；SSE 断线用 cursor 补齐/重新取快照；有历史数据的刷新失败显示非阻塞提示。表单未保存切页保留或提示，不能静默丢失。

## 10. 页面可观测性
概览突出需用户处理和当前状态；技术术语折叠至诊断。股票输入加可访问名称，异步状态合理 aria-live；配置编辑不称“只读观察”。键盘可访问、焦点返回原入口；检查窄屏、文本放大和错误提示。
