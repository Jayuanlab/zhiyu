# 12E 任务范围分页与聊天文件选择器

本批将实际聊天“从空间内添加”选择器迁移到有界分页。默认旧 GET、浮动面板、@ 提及及 insight 文件入口尚未全部迁移，方案 12 不验收。日常数据库未迁移，未发布或发送聊天消息。

## 修改

- bounded 入口支持 taskId/path。游标绑定 owner、任务和目录；改变查询范围返回冲突，不能用旧游标访问另一任务。指定任务先查 owner 再解析目录，子目录返回路径仍相对任务根目录，防止添加附件时路径被截断。
- 新增共享分页 hook：读取与合并、空扫描页继续、失败保留/重试、权限变化清空、失效重扫；查询范围改变时清空旧列表并以代际标记丢弃旧请求结果。初始读取在微任务中复核代际，减少开发模式重复 effect 产生的首段请求。
- 聊天原来有独立内嵌选择器，共享文件未被实际引用。本次删除重复实现并接入共享组件；显示部分结果/筛选口径、继续和重试按钮；选择结果仍进入原附件引用状态。组件宽度受父容器限制。
