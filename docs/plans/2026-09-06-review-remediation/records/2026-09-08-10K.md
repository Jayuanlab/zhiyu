# 10K 运行事件历史分页

## 修改

事件 API 新增 `pagination=history` 和排他的 before 序号。每页最多 2000 条，数据库多读 1 条判断 hasMore，返回时间顺序一致的事件与 nextBefore。查询仍先核对 owner，再按车间和运行在数据库侧过滤；不扫描全部结果后才分页。校验非法/冲突游标与页大小，保留原 after 增量读取。

运行历史 hook 保存续页位置，按事件 ID 合并；加载失败原页重试，成功刷新重新读取首段。页面明确“尚有更早事件、当前记录可能不完整”，提供加载更早记录，不把最近 2000 条当作完整运行证据。

## 限制

游标是当前车间单调序号，不是不可变历史快照；新事件通过刷新或原增量通道获得。仅验证本批 2052 事件 fixture，不推导无限历史的渲染性能已达标。运行记录展示模块及其余面板拆分、完整竞态覆盖和生产性能验收继续推进。日常库未迁移，未执行外部业务动作。
