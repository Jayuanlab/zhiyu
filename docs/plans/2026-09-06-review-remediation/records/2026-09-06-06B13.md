## 改动

新增主人限定的 GET `/api/workshops/[id]/manifest`。在 PostgreSQL 只读 REPEATABLE READ 事务中读取 Work、命令版本、完整 Loop 配置、内部名称与资料源，返回不缓存的 YAML 编辑基线。超过 10,000 条 Loop 或源时明确失败，不静默截断编辑内容。归档任务不进入可修改清单，历史记录仍保留。

删除前端从 dashboard 摘要拼接 YAML 的旧函数。它遗漏 mission 字段名，且把 context/actionPolicy/verification 等字段写为空值。现在打开编辑器时加载完整配置，提交与审核始终使用打开时的目标 ID；提交携带打开时的命令版本，不使用后台刷新的版本。冲突保留用户草稿，并在弹窗内提示核对最新配置。

浏览器截图复核发现长审核报告使弹窗底部超出视口，已限制弹窗最大高度为 85dvh 并允许内部滚动；真实浏览器确认应用按钮可滚动进入视口。

往返测试还发现导入器丢弃 control 和声明扩展字段。现在将无独立列的 spec 字段与 metadata 扩展保存在 modelConfig 的 manifestSpec/manifestMetadata 内；排除 modelConfig 本身和已有独立字段，避免重复导入导致递归膨胀。导出重新还原 control、role、labels、annotations 等。历史缺失 control 时，由车间名称与 mission 生成候选，并在 YAML 顶部和响应 warnings 明确提示核对，不声称恢复了历史原文。
