## 复现与修复

原车间事件证据查询只核对 owner hint 中的车间编号和事件编号，没有再次校验车间所属用户。隔离库用错误来源提示成功读取了其他 owner 的事件内容，见 [修复前失败](11H-evidence-before-postgres.json)。这是来源读取边界的真实缺口，不意味着已经证明某个公开 HTTP 入口可任意构造该提示。

车间事件查询现在以同一 SQL 子查询要求车间 userId 等于可信请求用户，保留事件/车间对应关系校验。UUID 事件表查询前过滤非法旧引用和非法车间提示，不能让一个旧字符串造成整批 UUID 转换失败；没有解析的引用保留 unresolved、空正文和空时间。无效或越界时间值返回未知时间，不伪造日期也不抛出范围异常。
