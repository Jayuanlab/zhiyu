# 09M 开发与生产进程管理入口

Web 包的 `dev` 和 `start` 改用同一管理入口。读取配置时进程环境优先、`.env.local` 优先于 `.env`，worker 模式要求显式主人；确认真实 worker 的持久租约心跳后才启动 Web。开发预热脚本不再强制设置 ENABLE_LOCAL_SCHEDULER=true，后台子进程隐藏窗口。embedded/disabled 不创建新 worker，disabled 仍优先。

管理入口只管理自己创建的子进程，输出 Web/worker PID 和生命周期事件。重复启动由数据库租约拒绝，不能启动另一套 Web 并伪装成功。停止时先请求 worker 停止，最长等待 35 秒，再清理自己的 Web 进程树；worker 不确认或意外退出均返回失败。父 IPC 断开请求停止，避免留下失去管理的进程。没有自动重启或静默接管其他实例。
