## 实际变更

- Web 订单、撤单和命令查询接入签名 v2 接口；身份来自会话，commandId 必填。超时返回未知及原命令编号，重试复用编号；交易理由与撤单原因参与不可变命令意图校验。
- 车间使用 runId 与调用方稳定编号组成命令键。签名携带当前车间、执行租约和策略摘要；0144 迁移提供受限数据库函数，在 Python 账户事务前后检查角色、策略、运行状态及租约。事务中租约失效导致全部回滚，已存在的命令结果仍可查询恢复。
- 车间附属事件使用既有 recorded-step 接口去重。MCP 单测验证稳定键和上下文传递，不能单独作为附属事件实际数据库去重证明。
- 已配置 PostgreSQL 账户时，账户、订单、成交读取同步切到 v2，缓存按账户存储版本及主人区分。服务错误不回退旧账本；尚未配置时旧 JSON 仅作只读参考，标记需要迁移并禁用交易。
- Python 源码旧下单、撤单和保存入口明确拒绝，GET 保持纯读。日常旧服务尚未重启，不能把源码退役等同于运行时切换完成。
