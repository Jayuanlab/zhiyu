# 09A 模块隔离与停止协议

本子步骤实现 `apps/web/lib/runtime/module-supervisor.ts`。每模块独立周期、超时、占用、起止时间、最后成功、耗时及跳过原因。慢模块不阻塞其他模块，同模块未结束不重复启动；跳过只更新独立跳过字段，不覆盖当前运行起点/结果。异常被限定在对应模块。

pause 仅停止新启动；stop 发出 AbortSignal 并有界等待。超时或停止后未确认底层结束时保留 inFlight/stopping，返回未结束模块列表；即使底层随后 resolve，也标记 settled_after_abort，不声称外部效果已取消。调度微任务尚未执行时收到 stop，不再调用底层操作。时长验证拒绝 Node 定时器溢出区间。

## 持久宿主租约与心跳

0146 新增 runtime_instances 和 runtime_owner_leases：按主人约束当前实例，保存模式、期望状态、实际阶段、启动/心跳/停止时间及结构化模块状态。RuntimeHostStore 使用数据库时间和主人范围事务锁领取；同实例活跃领取重试返回原 token，另一实例不能同时领取。过期接管递增 token，并保留旧实例 lost 状态；旧实例不能再续约、覆盖当前状态或释放新租约。UUID 在领取前规范化，避免大小写导致不同锁键。
