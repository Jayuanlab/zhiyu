# 09H 外发恢复接入统一宿主

外发恢复注册为独立模块，每次最多核对 10 条，模块超时 3 分钟。复用 07 的恢复记录、领取租约、退避和主人核实决定重放，不新增发送能力。宿主主人和实例 ID 显式传入；errors 和 unconfirmed 分别暴露错误码，未知结果不能记作恢复成功。

recoverOwnedOutbox 接收取消信号，在首次访问前、每次领取前、领取返回后及每次 provider 调用前检查。停止后不领取下一项，也不发起新的状态查询或核实调用；已发出的请求仍等待底层返回和原事务核对，再释放模块占用。取消不等于已撤销外部操作。既有命令 ID 和未知结果恢复规则保持不变。
