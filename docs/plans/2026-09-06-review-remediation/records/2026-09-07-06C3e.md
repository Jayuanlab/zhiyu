# 06C3e：无凭证 Run 写入限制与主人 Outbox 审核

本步骤封闭受控 Run 的无上下文事件/草稿写入，同时保留主人审核旧草稿的行为。06 整包、07 外部发送及全部 12 个方案尚未完成。

## 改动

- 无执行上下文且指定 Run 的事务先锁 Work，再核对 Run 归属、当前租约及完成回执。当前受控 Run、已经完成的受控 Run、租约已转给下一 Run 后的历史受控 Run，均拒绝无凭证写入。
- 同一事务内追加的事件也检查目标。不存在或不属于该 Work 的 Run 返回 not_found；实际未使用租约的遗留 Run 保持原有语义。
- 预览、发送和自动发送在边界检查/状态修改/外部调用前校验执行身份。自动发送的身份拒绝放在异常恢复分支之外，不能因拒绝反而改写失败状态。
- 主人预览/发送由 Work Runtime 核对归属后提供宿主审核身份；模型执行上下文不能切换为该身份。主人审核事件作为新的 Outbox 操作，runId=null，使用 sourceRunId 保留草稿来源，并记录真实 actorId。HTTP JSON 不能提供这项宿主能力。
