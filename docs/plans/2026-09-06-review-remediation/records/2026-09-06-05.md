## 已落地

- `AUTH_MODE` 未设置默认 authenticated；只有显式 local_owner 才返回本机主人 session。当前本机 `.env` 已显式配置 local_owner，密钥不写入本记录。
- Next proxy 验证 Host 与 URL、同源 Origin；拒绝跨站和缺 Origin 的写请求，不信任 X-Forwarded-*。拒绝包含 commandId、reasonCode、policyVersion 的日志和响应。脚本不能通过伪造 actor 获权。
- 本机模式的 Next 启动要求显式回环 hostname；默认 start/dev-with-warmup 已回环绑定。其他 dev 变体未显式绑定时会安全失败，需补 `--hostname 127.0.0.1`。
- 旧 guest 路由在登录模式拒绝，在本机模式仅跳转首页；credentials 拒绝旧 @guest.local 身份。不会再隐式创建用户。
- HTTP 模拟订单 actor 来自 session；MCP actor 来自服务端 Work 和 owner。量化订单、撤单、自选池修改各自补 session 检查。
- 原生密码回传仅消费属于当前 owner、五分钟内的服务端命令，执行前删除一次性请求；不执行客户端 originalCommand/cwd。权限回传拒绝跨 owner、非法 decision 和未经重新审核的 updatedInput。
- 工具 registry 记录交易员/自选股猎手硬禁止角色；矩阵、SDK 可见工具、MCP 实际执行共用禁止决策；直接名和 MCP alias 归一化，denied 优先。MCP 执行前重新检查 Work 所有权、当前工具策略和边界是否变化。
- Python 量化写入口与仍有副作用的旧账户/订单读取要求内部凭据；微信缺配置、缺凭据、无效凭据均拒绝。Web client 和本地依赖启动脚本同步读取服务端凭据；服务只允许回环启动。
- 账户设置增加身份模式状态；[写入口清单](05-write-routes.json)记录 164 个写路由。39 个没有内联 `await auth()`，其中包含调用 requireBrainUser 等共享鉴权函数的路由，并不等于 39 个未鉴权漏洞；清单测试会阻止新增入口无记录。

## 失败与纠正

1. Python TestClient 导入失败：当前 Starlette 要求尚未安装的 httpx2。未改依赖，改为构造 Starlette Request 调用实际中间件；合法调用连接 fake 业务执行器。此回测不能冒充真实 TCP 端到端测试。
2. 首轮构建期间盘点到 guest 隐式登录路径，主动停止本人启动的 Next build 进程，退出码 4294967295；构建脚本已恢复 tsconfig/next-env，保留 [中断日志](05-build-interrupted.log)，修正后重建。
3. ensure-secrets 首次误在仓库根执行，生成了此前不存在的根 `.env`。已删除该次新文件，在 apps/web 正确目录重跑；未覆盖既有 Web 配置，未输出密钥。
4. 首次生产 smoke 在构建收尾前启动，session 响应为空导致 JSON 解析失败；已改为等待完整构建并校验 JSON Content-Type。该临时库已清理，见 [第一次记录](05-postgres-first.json)。
5. 完整构建后正常回环请求被 Host 检查拒绝。查明 NextURL 将 127.0.0.1/[::1] 归一化为 localhost；真实 NextRequest 的 [失败单测](05-nexturl-before.json)复现，修正为允许同端口的回环别名，但 Origin 仍必须匹配原始 Host，不能把 localhost 和 127.0.0.1 的浏览器来源混用。[修复后单测](05-nexturl-after.json)通过；[生产失败记录](05-postgres-nexturl-failed.json)保留，临时库已清理，修复后重新构建。
6. 设置页检查显示身份模式正常、浏览器 error 数 0，但服务器发现 Next 图片优化器内部请求公开 logo 时无正常浏览器 Host，被新边界误拒绝。已给 /images、/icons、/fonts 下指定图片/字体扩展名的 GET/HEAD 加公开资源例外，API 和写请求均不豁免；6 项定向身份单测通过。停止本人启动的候选 26988 后重建，最终生产 smoke 的两种模式 logo 优化请求均返回 200/image；再次打开最终候选设置页，身份展示正常，浏览器 error 数 0，服务器 stderr 无新增错误。

## 发布与剩余边界

日常 3515 尚为原生产产物；候选构建和隔离测试不代表已经上线。Web/Python 必须配套重启才能启用内部凭据与只读账户接口。

本阶段验证本机边界和现有真实登录链路，不代表已完成所有共享多租户资源隔离。模拟账户文件、主机工作区/存储/桌面自动化仍有单主人语义，共享部署保持未验收，不能仅把 AUTH_MODE 切为 authenticated 后开放公网。脚本型 Web 写入当前拒绝缺 Origin；尚未开放通用内部 HTTP 写通道，worker 使用领域接口。

当前日常主人资料仍是历史 guest.local 账号，本机身份保持可用；共享迁移需先给真实主人绑定可登录的常规身份。本次真实登录测试使用临时常规用户，没有擅自更改日常邮箱、密码或用户 ID。
