# 06D2：车间原生 Loop 接入执行租约

## 本次修改

原生车间 Loop 先通过命令账本接受同身份 Work Run/LoopRun，再领取 Work 执行租约，领取失败明确返回 busy。执行期间续租，AbortController 传入原生执行器，SDK 工具调用前检查执行权，MCP 工具显式携带同一租约。

LoopRun 完成、审批请求、LoopState 更新、结果检查点和结果事件在同一受令牌保护的事务内提交。状态合并读取事务中的最新值，保留执行过程中新增的状态字段。Work 完成事务核对已捕获结果并释放 Loop 占用；若该事务失败，重试读取检查点，不再次调用执行器。

过期执行者不能完成运行或回写状态；没有租约的旧完成入口也不能改写已经关联 Work 执行的 LoopRun。旧中断扫描排除这类运行。发生外部动作意图后失租，Work 与关联 LoopRun 转入 needs_review，保留占用并拒绝自动重放。
