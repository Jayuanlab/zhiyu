## 修改与边界

车间页面的运行请求、追加方向、模板/自然语言任务创建、任务暂停/恢复/归档、任务激活/驳回、清除阻塞、配置提案处理、历史配置恢复和车间删除，接入既有持久命令客户端。删除先读取目标及版本，再显示确认；核对已删除车间后不继续刷新其详情。运行接受后明确显示排队，未把接受等同执行完成。

新增显式路由结果契约，按入口校验 workshop、run、directive 或 loop 的真实目标，避免不同动作共用错误的成功判定。预览、立即执行、外发和审批后恢复没有自动接入重放。命令内容冲突保留原请求供核对；普通业务拒绝进入终态并保留当前草稿，未知服务错误继续保留待核对记录。

指令和自然语言任务输入在发送时捕获原文，成功或核对后仅清除仍与原请求相同的输入；提交期间的新文字保留。各新增命令 HTTP 入口检查 X-Work-Actor 与真实会话一致，防止页面身份过期时以新身份执行旧请求。

补齐 Loop 不存在、缺少必填字段、提案已激活/驳回或无效等明确拒绝代码；这类拒绝可通过账本保存 failed 回执，避免客户端永久停在结果未知。未知提案/任务执行错误返回 500。
