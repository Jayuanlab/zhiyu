## 实施内容

- 0127 新增 work_commands 与 work_command_targets，唯一键为 owner_id + command_id。命令保留 payload、SHA-256、目标、类型、期望版本、结果、错误码和时间。删除 Work 不删除所属用户的命令回执；删除用户仍按所有权级联清理。
- command-payload.ts 对 JSON 对象键排序，保留数组顺序；拒绝 undefined、非有限数、Date、Map、稀疏数组、函数、循环引用及 symbol 键，避免有损序列化造成不同命令被当成相同命令。调用前固定 payload 快照，日期必须由业务入口显式转换为协议字符串。
- acceptLocalWorkCommand 在单一事务内检查所有权、唯一键与 hash、版本，并提交 queued 账本和 accepted 事件。事件失败则接受记录一起回滚。重复请求返回已持久化回执，不追加重复事件。
- executeLocalWorkCommand 按命令、Work、版本、事件计数器的顺序锁定；数据库内 handler 使用传入 tx 和持久 payload。业务状态、版本递增、结果、applied 事件一起提交。版本过时写入 failed/version_conflict 及事件，且不调用 handler。
- 执行失败或进程退出时事务回滚，命令保留 queued，可由调用方显式重试。成功结果重放不再执行 handler。getWorkCommand 按 owner 查询回执；getWorkCommandVersion 按当前所有权查询本账本版本。
- 新入口仅支持 PostgreSQL；SQLite 明确拒绝，不使用进程锁模拟持久一致性。
