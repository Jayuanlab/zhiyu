# 06C7：受租约约束的队列消费者（实施中）

## 实现

新增 consumeOwnedWorkRuns：按 owner 读取活动车间的 queued 运行或租约过期运行，执行前通过现有 Work 租约准入；队列读取本身不授予执行权。每轮有上限，优先恢复过期运行，遇暂停、活跃租约、旧执行器或 needs_review 时不能越过边界。

消费者调用真实运行生命周期，传入租约、续租间隔和中止信号。已有检查点沿 06C6 恢复；有外部动作且租约过期时转 needs_review，不自动重放。错误保留运行及租约状态供下一轮核查，不在 catch 中伪造成功。

新增 consume-work-runs CLI：明确 owner，可单轮或持续运行；中止时停止新领取并传递 AbortSignal，结束后关闭数据库。要求 PostgreSQL 模式且显式禁用旧 scheduler/startup listeners。宿主健康、自动启动、旧调度切换和 Loop 互斥联调属于后续 09，未切换日常服务。
