# 12I CI 分层配置与本机命令验证

## 修改

`.github/workflows/test.yml` 保留 lint、类型与 Node 22/24 单测；类型检查前构建共享包，并使用 noEmit。新增独立任务：临时 PostgreSQL 的迁移契约/文件边界/无浏览器 worker，Python 模拟盘 fixture，以及隔离生产编译。数据库凭证只用于临时服务，关闭启动监听器；集成与构建任务无论成功失败都上传回测证据。各任务设定超时。

新增 [运行支持矩阵](../../../reference/runtime-support-matrix.md)，明确 Windows 开发/单 worker 的局部验证、生产组合与共享部署待验收、Ubuntu CI/SQLite/Tauri/远程环境未验证。当前实测 Node 24.14.1、pnpm 10.14.0、Python 3.12.10；未把 CI 配置的 PostgreSQL 16 写成本机实测版本。

## 本机验证

- YAML 经现有 `yaml` 解析器读取成功，包含 pre-test/test/postgres-runtime/python-paper/production-build 五个任务；两个数据库任务均配置 PostgreSQL service。
- 在 tools/quant-service 执行 `.venv/Scripts/python.exe -m unittest discover -s tests -p 'test_paper*.py' -q`：退出 0，17 项测试通过，耗时 0.036s（unittest 统计）；无真实交易动作。
- `node --import tsx --conditions=react-server scripts/test-isolated-migrations.mjs --runtime-host-cli --record-prefix=12I-ci-worker`：2026-09-08 22:01:00—22:01:15，隔离库 146 迁移/131 表/1566 字段通过并清理。真实 CLI 无浏览器启动并执行排队 dry-run、首心跳 480ms、暂停/恢复/只读状态/确认停止、新旧入口遵守禁用配置均通过。见 [结果](12I-ci-worker-postgres.json) 和 [子进程记录](12I-ci-worker-cli.json)。
- 迁移命令复用 [12H 本轮结果](12H-migration-postgres.json)，文件服务复用 [12E 真实范围与大文件树结果](12E-scoped-postgres.json)。生产编译等待 12H 候选 69 结果。

## 验收限制

以上是 Windows 本机命令证据和 YAML 解析，不是 GitHub Actions 的 Ubuntu 执行结果。没有推送、触发或查看远端 CI run；远端依赖安装、Linux 路径/进程行为、Node 22/24 矩阵以及实际 artifact 上传仍待验证，CI 项不能标记已验收。当前阶段不改变日常服务配置或数据库。
