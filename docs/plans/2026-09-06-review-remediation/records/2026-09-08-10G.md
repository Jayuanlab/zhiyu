# 10G 审核记录深链接

## 范围与设计

HEAD：`a0e94e5f19661895adce29787da85385117f2477`，保留已有未提交修改。T10-1 的审核位置由 workId/reviewId 表示，直接链接默认打开审核页签，刷新、复制和后退恢复目标；切换车间、离开审核页签或关闭详情清除对应位置。

原列表只读最近 200 条 pending，已处理或较早记录不能靠该列表可靠定位。增加按 ID 的只读查询，先验证 owner 对车间的权限，再同时约束审核条目及原始事件的 workshopId；没有权限与不存在统一返回 404，非法 ID 返回 400。不修改原始事件，不新增审核执行入口。

新增 `use-workshop-review-location` 管理目标读取、loading/error/retry 和请求取消，目标变更只展示匹配 key 的响应。前端 pending 目标补入当前车间操作列表，关联事件也从详情补齐；已处理目标仅展示状态及更新时间，并从操作列表移除。三类既有卡片（通用、智能体变更、自选股提案）提供可复制的定位链接。操作继续使用已有处理函数。
