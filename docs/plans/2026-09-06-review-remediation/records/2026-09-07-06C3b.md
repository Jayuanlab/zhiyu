# 06C3b：执行凭证沿 MCP 异步调用进入命令事务

本步骤完成可选执行凭证从执行器到 MCP、再到命令账本的传递。06 整包及全部 12 个方案尚未完成；原生工具、非命令写入、消费者和 Loop 抢占仍需继续实施。

## 改动与控制边界

- 新增服务端 `execution-context.ts`，通过 AsyncLocalStorage 传递不可变凭证快照。并发请求彼此隔离，嵌套调用不能用另一份凭证替换当前凭证，undefined 也不会清除已有上下文。
- MCP server 创建时捕获凭证；每次工具调用核对主人、Work、Run 并检查当前租约，随后在同一异步上下文中执行工具。仍保留原有归属和实时边界策略检查。
- `executeWorkshopAgent` 可接收服务端凭证并传入 MCP。命令账本自动读取上下文，因此现有公开命令入口无需把凭证加入业务 payload 或模型参数。
- 数据库命令继续使用 C3a 的事务内前后校验：工具开始前的检查不能代替提交前的校验。上下文只传递身份，不为未迁移的外部动作授权。
