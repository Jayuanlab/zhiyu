# 06E5：通用 Loop 触发入口收紧

日期：2026-09-07。处理 `runLoop` 原先绕过接受命令、直接创建 Run 与写状态的路径。

## 修改

- `runLoop` 必须持有服务器侧租约；主人、车间、Loop 绑定和可选 executionId 必须一致。无租约的车间 Loop、独立 Loop 均拒绝，不能凭参数自行取得执行能力。
- 使用已接受的同一 Run，不再新建运行记录，也不覆盖接受时的请求/输入。
- 在对应车间租约事务内，将 queued 转为 running、更新 Loop 阶段并写 `loop_trigger_started` 事件。重复触发 running Run 只返回同一身份，保留已经产生的观测；完成后的 Run 拒绝重新开始。
- 事件失败时 Run 转换、Loop 状态和观测一起回滚。取消后的旧租约不能再触发。
