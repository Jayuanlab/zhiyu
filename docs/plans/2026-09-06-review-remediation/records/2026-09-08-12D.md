# 12D 工作区页面接入有界分页

工作区对话空间页面开始使用 `pagination=bounded`。其他文件选择器、任务内列表和默认旧 GET 尚未迁移；T12-7 与最终生产验收仍未完成。

## 用户路径

- 空扫描页依据 hasMore 继续，不再按文件数为 0 判断结束。页面明确显示已加载数量、尚未完整，以及筛选仅针对已加载文件。
- 提供“继续扫描”；请求期间同步锁防止重复操作。已有文件在继续读取期间保留，不因加载下一页全部消失。
- 网络/503 可用原 cursor 重试；410/403/401/422 提示重新扫描。403/401 清除旧展示；410 保留旧展示供参考，重扫成功替换旧列表。刷新失败后重试仍重新开始，不把新首段追加到旧列表冒充完整。
- 对话空间使用显式继续入口，避免空页时滚动条不足以触发下一页。其他标签页原加载行为保留。
