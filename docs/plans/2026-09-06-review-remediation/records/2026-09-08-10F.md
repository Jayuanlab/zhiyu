# 10F 运行记录深链接

## 范围

本批落实 T10-1 的运行定位部分，审核 `reviewId` 定位尚未接入。HEAD 为 `a0e94e5f19661895adce29787da85385117f2477`，保留已有未提交修改。

原页面只靠弹窗内锚点定位，且最多读取最近 2000 条车间事件。旧运行即使存在，也可能落在窗口外。URL 现在用 `workId/runId` 表示用户正在查看的运行，关闭弹窗清除 runId，后退可恢复。具有关联运行的记录提供可复制、可新窗口打开的定位链接。

## 实现与边界

- `events` API 新增 UUID 格式的 runId 筛选，传入 Work Runtime，再由事件查询按 `workshop_id AND (run_id OR loop_run_id)` 过滤。先校验当前 owner 的车间访问权；runId 只定位记录，不赋予权限。
- 查询在数据库侧先按运行过滤，再截取最近事件，避免通过扩大全车间查询窗口碰运气。单次弹窗仍最多读取 2000 条事件，页面说明该范围，不宣称已加载完整历史。
- 前端在已授权的车间列表内解析 workId；切换车间清除运行位置。慢请求的旧回执不写回当前查询，显示也核对车间与运行归属。
- 没有可访问记录与读取失败区分，失败保留重试入口。原始事件和业务状态不变，不执行任何运行/审批命令。
