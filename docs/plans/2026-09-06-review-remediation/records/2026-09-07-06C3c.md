# 06C3c：SDK 执行前钩子与失租中止

本步骤为 Claude SDK 的两条工具执行路径增加执行前租约检查，并让车间执行器在检测到失租时中止。仍不是 06 整包或全部 12 个方案的完成验收。

## 改动

- AgentOptions 增加仅供宿主提供的 `onBeforeToolUse`。Claude 的常规运行和计划执行两条 query 路径都安装 `PreToolUse` hook，独立于 `bypassPermissions`，没有修改原权限策略。
- hook 成功只返回空结果，不返回 allow；失败明确返回 deny、continue=false，并中止 AbortController，避免把可选 hook 异常误当成允许执行。
- 新增 `createExecutionGuard`，每次检查都使用 PostgreSQL 租约及运行状态。凭证失效、归属错误、检查异常或已取消都会中止本次执行。旧 controller 不可被替代执行者复用。
- 车间执行器核对凭证目标，在准备执行前、每条模型消息处理前及流结束后检查；SDK 工具派发使用同一 guard。受控执行被中止后向上抛错，不继续将部分输出解析为成功结果，也不在该 catch 中追加未经校验的错误事件。
