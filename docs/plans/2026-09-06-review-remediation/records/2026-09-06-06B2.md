## 修改内容

- 三个 Work Runtime 入口调用持久账本，重复 commandId 返回保存的结果；不同内容冲突，旧版本拒绝。配置、Heartbeat、Loop 调度状态、Work 版本快照和关键事件使用同一事务。

- 增加结果编解码，保留 Date 类型和普通字符串的区别，统一日期路径排序；无效日期和循环对象拒绝。删除把 commandId 当成事件外键写入快照的做法，快照引用真正的事件 ID。
- 配置 PATCH、Loop 暂停/归档、版本恢复、通用 commands 接口接受 commandId/expectedVersion，提供 400/404/409 的拒绝结果；新增 owner 范围的持久回执 GET。配置详情返回 commandVersion。
- updateWorkLoop 不允许通过普通 patch 将 Loop 移出当前 Work，转移需要独立的所有者审核流程。
