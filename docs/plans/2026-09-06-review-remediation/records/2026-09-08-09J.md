# 09J 持久宿主状态查询

运行状态 API 和 Loop 页面状态数据新增独立 web/worker 字段。Web 响应正常不等于 worker 在线；worker 在线以数据库租约和实例状态为依据，同时返回配置模式、实例模式、期望状态、心跳时间/年龄、租约到期时间及模块状态。模块报错不改变仍在线的宿主判断，心跳过期保留最后已知模块状态并明确离线。

无实例记录为 offline/runtime_not_started，数据库或 schema 不可用为 unavailable/online:null，不能将查询失败当作“已停止”。查询仅按已认证主人读取，不启动进程。旧内嵌调度状态也检查主人一致性，避免共享进程中的其他主人状态进入响应。未知模块异常详情收敛为错误码；API 失败返回 503/runtime_status_unavailable，不向客户端回传原始异常。
