# 03 量化质量与刷新：回测记录

日期：2026-09-06。状态：已验收，回测通过；验证对象为独立生产构建和隔离行情/数据库。

## 实施范围

沿用既有行情源，增加 quant-quality.v1 质量信封，保留来源观测、抓取、生成、过期时间；旧缓存未提供观测时间时显示未知。scope 区分全市场、自选股、样例、未知。交易日历版本尚未提供时为 null，不以自然日推导交易许可，撮合门禁由 08 处理。

页面改为共享 SWR 读取 page-state，预热阶段 2 秒、通常 15 秒、刷新错误 60 秒；隐藏页面停止轮询。独立显示错误与缓存数据，保留有效 0，未知数为 —。缓存冷请求合并，失效前的未完成请求不得写回覆盖新缓存。

发现原账户 GET 会撮合并保存，因此新增 /paper/account/view，只读取已有账户，不初始化、不撮合、不保存。Web 账户读取切到新端点；旧 Python 服务不支持端点时返回错误，不回退调用有副作用的旧端点。03 不移除旧撮合入口，08 负责其事务改造。
