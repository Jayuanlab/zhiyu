# 12C 有界文件扫描与独立分页入口

本批新增 `GET /api/workspace/files?pagination=bounded&pageSize=50`，尚未将默认工作区和所有文件选择器迁移到新入口。旧默认路径仍可能全量扫描，T12-7 不算完成。未改日常数据或运行服务。

## 实现契约

- 每页最多 500 次目录项读取或下一任务根查询，pageSize 为 1—1000；opendir 缓冲 32 条，递归深度上限 32，最多 32 个进程内扫描会话，闲置 120 秒关闭句柄。超过深度明确报错，不伪装为扫描完成。
- 授权任务按 ID keyset 每次只查询 1 条，避免先加载全部用户任务。继续读取及回放上一页时重新核对 owner；路径使用 12B 的边界校验，跳过符号链接/junction 并报告跳过数量。
- cursor 按 owner 绑定。上一续页请求重放返回原页、不推进下一页；过期/进程重启/过旧游标返回 410，忙碌返回 409，容量限制 429，用户撤权 403。返回 total=null、directory_traversal 排序，不声称知道全量总数或最新文件全局排序。
- 无可展示文件但扫描预算耗尽时 files=[]、hasMore=true，消费者必须继续读取。此语义需要配合页面修改，不能直接沿用旧页面“空页即结束”的逻辑。

- 针对性测试 10 通过、0 失败，包含真实临时目录 1200 文件、32 项测试预算、空页续扫、丢失响应后的续页重放、跨 owner、撤权、失效游标与参数边界。路由测试证明显式新入口不会进入旧全量扫描。见 [单测](12C-bounded-first.json)。
- 真实 PostgreSQL 与文件系统集成：21:29:44—21:29:51；146 迁移、131 表、1566 字段通过，隔离库和临时文件已清理。1200 文件、13 页、最大扫描 101 项/页（配置预算 500）；路径无重复或遗漏，其他 owner 根路径解析次数为 0，真实数据库改变任务归属后旧游标拒绝。见 [集成报告](12C-bounded-postgres.json)。
- Windows / Node v24.14.1 单次样本：扫描约 2940.44ms，进程 heapUsed 差值 7,577,048 字节。文件刚写入，缓存温度未控制；差值受 GC 和依赖影响，不是内存峰值或性能 SLA。
- 类型检查退出 0。没有页面代码变化，本批未进行浏览器页面验收，也未重复全 Web 回归。指纹见 [源码哈希](12C-source-hashes.json)。
