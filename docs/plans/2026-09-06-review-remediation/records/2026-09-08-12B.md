# 12B 文件列表的授权根目录与路径边界

本批落实 T12-7 的安全前置条件；有界分页和压力指标仍待实施，方案 12 未验收。未改日常文件、数据库或生产服务。

## 修改

- 工作区 GET 先查询当前用户任务 ID，再把集合传给文件遍历；有授权集合时直接从集合建立任务根目录，不枚举全部会话目录再过滤。空集合不触碰文件系统。
- 任务 ID 拒绝路径分隔符等非法字符；列表路径同时检查规范化路径与 realpath，拒绝越界。任务根和子路径上的符号链接/junction 不被跟随，嵌套链接条目不进入递归列表。
- 列表不复用此前的 30 秒目录内容缓存，避免目录替换后旧缓存继续显示已失去路径依据的内容；原失效通知函数保留兼容入口。此举可能增加重复读取成本，待有界分页/索引方案解决，不能宣称性能提高。
- GET 的边界异常返回安全的 403，其他读取错误不返回宿主路径和原始异常内容。

## 后续必须完成

当前遍历仍读取所有已授权任务文件再分页，内存/遍历量无界；授权 ID 的 DB 查询也尚未分页。需要改为受限扫描或索引、可恢复 cursor，并同步文件选择器/工作区等消费者，避免空扫描页或部分结果被误当全部完成。符号链接/junction 当前整体不支持跟随；并发替换路径的检查到读取时间窗尚未提供 OS 级原子保证。读文件/写文件/预览接口需单独核对实际权限，不以列表检查证明其他动作安全。T12-7、支持矩阵与最终生产验收保持未完成。
