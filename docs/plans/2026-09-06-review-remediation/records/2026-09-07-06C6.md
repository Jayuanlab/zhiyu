## 本步控制边界

- 被控对象是同一 Run 的已保存模型输出和输出动作回执。先验证当前租约，再读取不可变检查点；有检查点则跳过上下文重新取样、指令规划和模型调用。
- 使用检查点内 directiveIds，不能消费保存输出之后新到达的指令。已提交动作通过原 step key 读取回执，未提交动作在当前租约下补齐。
- 首次模型失败的检查点直接收敛为失败，不能自动重新生成结果或执行其中的部分结构化动作。
- 已开始外部动作后的失租仍由现有 needs_review 边界阻止自动接管，本步不解除该边界。用户可核实已有 Outbox；运行恢复托管和队列消费者仍需后续接入。
