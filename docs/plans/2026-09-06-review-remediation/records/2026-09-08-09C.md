# 09C 后台入口与 Work 执行接入

本阶段接入 `scripts/start-runtime-worker.mjs`，提供 `pnpm runtime:worker` 和 `pnpm runtime:status`。显式 worker 模式、主人 UUID、PostgreSQL 配置检查在加载业务模块前完成；不修改日常环境、不执行迁移。启动先取得实例租约并写心跳，随后加载业务模块，避免业务依赖冷加载阻塞首个心跳。

三个模块分别负责 Loop 持久排队、Loop 执行、车间运行消费，复用已有领域命令与执行租约。消费 Promise 保持到实际执行结束，传递宿主取消信号；返回的引擎 error 转为模块失败，不能记作扫描成功。Loop 扫描支持取消，已提交的排队命令保留，停止后不继续领取下一项，也不立即启动刚返回的命令。

进程支持 SIGINT/SIGTERM 以及本机父进程 IPC 的 pause/resume/stop。暂停保留持久心跳；停止有界等待并区分已结束、未确认与失租。状态查询只读，不增加实例。旧 Heartbeat CLI 移除强制启用，在 worker/disabled 下退出；其 embedded 兼容路径仍存在，尚未完成 Heartbeat 领域迁移。
