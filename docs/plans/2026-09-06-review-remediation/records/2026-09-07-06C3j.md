# 06C3j：Brain 辅助记录的执行写入约束

本步骤保护观测、通用快照、上下文日志和独立审核流水；06 整包及全部 12 个方案仍未完成。

## 改动

- 四类记录通过数据库事务写入；存在执行上下文时校验当前用户与租约，并在同一事务追加 brain_record_written 事件。事件只保存记录类型/ID、actor 与执行来源，不复制正文或上下文。
- 重复观测复用已有不可改写记录，不覆盖原文，也不新增写入事件；仍校验执行凭证。
- 快照来源 ID 规范大小写、去重，事务内确认每项引用属于当前用户。独立审核流水也核对目标记忆归属。
- 格式无效、不存在或其他用户的记忆引用统一使用 memory_reference_not_found，Brain HTTP 返回 404，不暴露其他用户数据或误报服务器异常。
- 租约只是执行身份约束，不是资源授权；现有服务权限模型保持独立。
