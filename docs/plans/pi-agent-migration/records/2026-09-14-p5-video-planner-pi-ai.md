# P5 独立入口与 Web Chat fallback 迁移记录

## 1. 阶段与环境

- 阶段/范围：P5 的独立入口切面与 Web Chat 低风险 fallback；迁移 `tools/ai-release-video-agent` 的无工具 JSON 视频规划调用，把 `/api/native/agent` 在无 Anthropic 配置时的纯文本 OpenAI-compatible fallback 改为 Pi AI，并让 Pi provider 支持 Web Chat 文本 run/plan/execute、文本类附件、PDF/Word 文本抽取、已选 RAG 文档和启用 skills 的只读上下文注入；不迁移 Wan 视频生成、Remotion 渲染、Web Chat MCP/sandbox、二进制/图片/文档原文件或真实外部发送。
- 状态：部分验收。
- 开始/结束时间及时区：2026-09-14，Asia/Shanghai。
- 基线commit、被测commit、dirty文件摘要：在 `zhiyu-pi` 工作树上增量修改；涉及 `tools/ai-release-video-agent/src/index.mjs`、`package.json`、`package-lock.json`、`README.md`、`apps/web/app/api/native/agent/route.ts`、`apps/web/app/api/native/providers/route.ts`、`apps/web/lib/ai/router/index.ts`、`apps/web/lib/ai/native-agent-plan-part.ts`、`apps/web/lib/ai/native-pi-file-attachments-context.ts`、`apps/web/lib/ai/native-pi-rag-context.ts`、`apps/web/lib/ai/native-pi-skills-context.ts`、`apps/web/components/agent/model-selector.tsx`、`apps/web/components/chat-context.tsx`、`apps/web/components/message/index.tsx`、`apps/web/lib/ai/extensions/index.ts`、`apps/web/lib/ai/extensions/agent/pi/index.ts`、`apps/web/lib/ai/native-pi-provider-capabilities.ts`、`apps/web/lib/ai/native-pi-openai-fallback.ts`、`apps/web/lib/ai/native-agent-plan-store.ts`、`apps/web/lib/db/schema.pg.ts`、`apps/web/lib/db/schema.ts`、`apps/web/lib/db/migrations/0156_add_native_agent_plans.sql`、`packages/ai/src/agent/types.ts`、`apps/web/package.json`、`pnpm-lock.yaml` 和本记录。
- Pi包名/精确版本/integrity、Node与包管理器：独立工具新增顶层依赖 `@earendil-works/pi-ai@0.85.1`；该工具使用 npm lockfile；Web 包通过 pnpm 声明直接依赖 `@earendil-works/pi-ai@0.85.1`。
- runtimeSnapshotId、实际模型/provider、配置来源：该独立工具不写 Work runtime snapshot。本段没有成功调用真实模型；`cc-sdk` 入口在当前本机环境返回不可解析 JSON 后按设计回退 heuristic。
- 模式：Node 语法检查、npm 依赖检查、离线/失败回退命令。
- 数据库/服务隔离方法、端口、数据目录、worker归属：未启动 Web 服务、数据库或 worker。
