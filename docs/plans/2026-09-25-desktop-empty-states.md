# 桌面 Web 空状态整理与验收

## 范围和设计口径

本轮只调整桌面 Web 中已确认的空状态：无智能体车间、文件工作区、已保存文件、消息理解待核对，以及 Web 端不可用的本地技能入口。空状态应先说明当前事实，再给出唯一明确的下一步；加载、筛选无结果、读取失败和真正没有内容分别呈现。后台运行状态仍可见，但不覆盖用户的起步操作。

## 已完成

- 车间无智能体时只显示一个居中的创建入口，保留后台状态，隐藏选择列表、未选中详情和无法使用的追加方向输入；创建仍经原 YAML 审核与权限边界。
- 文件工作区按笔记、我的文件、对话空间给出对应操作；筛选为空可清除筛选，扫描未完可继续，读取失败可重试且不会伪装为空。对话空间完成空扫描时不再另铺一块 0 文件状态卡。
- 已保存文件为空时只保留一个上传主入口；文件选择器仍可打开。读取失败与无存储空间有独立反馈。
- 消息理解待核对为空时显示“目前无需核对”并可进入已处置记录；尚未确认的提交不会显示完成空态。
- Web 设置侧栏隐藏仅本地客户端可用的技能入口；直接访问技能 URL 时显示中文说明和返回设置操作。
