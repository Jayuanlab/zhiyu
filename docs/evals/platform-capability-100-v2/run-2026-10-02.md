## 执行范围与配置

待测模型为 `qwen3.7-plus`，通过 Anthropic Messages 兼容协议运行 Pi harness。当前 JEV 1.13 配置为 `routing=replace`、`mode=off`、`targeted_retry=false`。这些是实际配置记录，不能仅由开关值推定每题路由效果或 JEV 决策正确率。

记录题绑定 2026-10-02 06:01:46 UTC 的数据库快照；来源题绑定同日 06:18:28 UTC 的源码快照。问答经过正式读取权限、投影、预算与分页逻辑，连接固定来源适配器。工作流由模型选择工具，调用正式服务，使用独立测试数据库、合成文件及隔离 provider，保存调用、前后状态和产物再核验。该轨道没有经过生产 Chat UI、实时业务检索或桌面按钮操作，不能视为生产端到端验收。

题目、金标与评分规则禁止进入待测检索上下文，实际读取以原始回执审计为准。评分分开记录答案实质、证据支持及工作流状态；服务检查通过不能代替模型解释正确。辅助模型判读没有人工正确标签，也没有匹配条件的 JEV 开关 A/B，因此本轮不能推导 JEV 准确率、自动确认修改的可靠性或生产决策成功率。
